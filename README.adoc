= UniProvider

link:https://docs.devcentr.org/uniprovider/[Explore the docs »] ·
link:spec/opr.md[OPR spec]
endif::[]

== About The Project

Every editor and agent shell inventing its own “detect Ollama / hard-code LM Studio / private unilayer manifest” story burns the same offline runners repeatedly.
**OPR** is a shared on-disk + optional HTTP registration format.
**UniProvider** is Dev-Centr’s D library, CLI, and localhost aggregator that implements OPR and (for now) probes a few well-known ports until runners ship their own manifests.

Other aggregators may implement OPR without depending on this repo.
That is intentional.

== Getting Started

=== Prerequisites

LDC or DMD, DUB.

=== Build

[source,powershell]
----
dub build --config=application
.\uniprovider.exe list
.\uniprovider.exe serve
----
