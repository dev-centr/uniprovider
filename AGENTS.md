# UniProvider

- **Language:** D (stdlib HTTP). Prefer HTTP for Tauri/JS consumers — see `bridge/README.adoc`.
- **Registry intent:** publish to DUB when the API stabilizes; until then treat this hive path as source of truth.
- Docs contribute to https://docs.devcentr.org/uniprovider/ once wired in the hub playbook.
